## ผลิตภัณฑ์ของเรา

### 1. บทสนทนาที่ "จำได้" ไม่ใช่แค่ "ตอบ"

ตัวละครทุกตัวมีระบบความทรงจำ 2 ชั้น — จำเหตุการณ์สำคัญที่ผู้ใช้เล่า (Memory)
และสรุปแก่นเรื่องทั้งหมดของความสัมพันธ์ (Rolling Summary) — ทำให้คุยวันที่ 100
ยังต่อเนื่องจากวันที่ 1 ซึ่งเป็นหัวใจของการรักษาผู้ใช้ (retention) ในธุรกิจนี้

### 2. ภารกิจ + ค่าความสนิท ให้เป้าหมายในการกลับมาคุยทุกวัน

- **ภารกิจประจำตัวละคร — ครีเอเตอร์กำหนดเองได้** — สะสมข้อความ แชทต่อเนื่องหลายวัน
- **ภารกิจสายสนทนา** — คุยจน "ทำให้เขาหัวเราะ" หรือ "เปิดใจสนิท" โดย AI เป็นผู้ตัดสินจากบทสนทนาจริง
- รางวัลคือ **ค่าความสนิท 5 ระดับ** (คนแปลกหน้า → คนรู้จัก → เพื่อนสนิท → สนิทใจ → ผู้พิเศษ) —
  ยิ่งสนิท ตัวละคร AI ยิ่งปรับน้ำเสียงการพูดให้เข้าใกล้คุณมากขึ้นจริง ๆ
  (ตั้งใจไม่แจกเหรียญ เพื่อไม่ให้เกิดเงินเฟ้อในเศรษฐกิจพลังงาน)

### 3. ใครก็สร้างตัวละครเป็น — และมีรายได้จากมัน

Creator Studio ให้ผู้ใช้สร้างตัวละครต้นฉบับ (ผ่านกระบวนการตรวจสอบก่อนเผยแพร่)
และ**แบ่งรายได้ 10% จากพลังงานที่ผู้ใช้ใช้ในการแชทกับตัวละครของตัวเองโดยอัตโนมัติ**
พร้อมแดชบอร์ดสถิติและบัญชีรายได้แบบ real-time

### 4. เศรษฐกิจพลังงาน (Energy Economy) ที่โปร่งใส

- แชทใช้พลังงานตามโมเดลและความยาวบทสนทนาจริง — คิดตามต้นทุน ไม่ใช่ตัวเลขลอย ๆ
- ระบบบัญชีแบบ ledger ตรวจสอบย้อนหลังได้ทุกรายการ หักล่วงหน้า→ตั้งเมื่อสำเร็จ→**คืนเต็มจำนวนถ้าระบบล้มเหลว**
- ผู้ใช้ใหม่และผู้ใช้ที่กลับมาแตะหน้าเว็บได้พลังงานฟรีรายวัน — เครื่องมือ retention ในตัว
- ร้านซื้อพลังงานพร้อมเปิด รองรับ 3 แพ็กเกจ (ต่อ payment gateway ภายนอก)

### 5. ค้นพบตัวละครที่ใช่

หน้า Discover จัดอันดับด้วย trending score ที่คำนึงถึงการเติบโตล่าสุด (ไม่ใช่แค่ยอดสะสมเก่า)
พร้อม search ภาษาไทย หมวดหมู่ และคลัง favorites ส่วนตัว

## โมเดลรายได้

| กระแสรายได้ | กลไก | สถานะ |
| --- | --- | --- |
| **ขายพลังงาน** (หลัก) | ผู้ใช้ซื้อแพ็กเกจพลังงานเพื่อแชท | ระบบพร้อม — รอเชื่อม payment gateway |
| **แบ่งรายได้ครีเอเตอร์** | จ่าย 10% ออกจากยอดแชทของตัวละคร (ต้นทุนอยู่ใน margin แล้ว) | ทำงานแล้ว |
| **Freemium** | พลังงานฟรีรายวันดึงการกลับมา ส่วนที่เกินซื้อได้ | ทำงานแล้ว |

## ความไว้วางใจ & ความปลอดภัย

- **ตัวละครต้นฉบับเท่านั้น** — ไม่รับตัวละครลิขสิทธิ์ผู้อื่น ตรวจทุกชิ้นก่อนเผยแพร่
- **ข้อมูลส่วนตัวแยกศาสตร์** — รหัสผ่านและการยืนตัวอยู่กับ Supabase Auth; กุญแจระบบทั้งหมดอยู่ฝั่ง server เท่านั้น
- **ทุก endpoint ผ่านการ validate** และตรวจสิทธิ์เจ้าของข้อมูลทุกครั้ง (ทดสอบป้องกันการเข้าถึงข้ามบัญชีแล้ว)
- **คุณภาพพิสูจน์ด้วยตัวเลข** — ชุดทดสอบอัตโนมัติ 196 เคส (unit/integration/E2E) และทดสอบผ่านเบราว์เซอร์จริงทุกฟีเจอร์หลัก

## สำหรับนักพัฒนา

```bash
npm install
cp .env.example .env        # ใส่ค่า Supabase + OpenRouter key (ดูคอมเมนต์ในไฟล์)
npx prisma migrate deploy   # หรือ migrate dev บน database ใหม่
npm run dev
```

> หมายเหตุ: โปรเจกต์นี้แชร์ Supabase database กับโปรเจกต์อื่น — **ห้ามรัน `prisma migrate dev`**
> กับ database ที่ใช้ร่วมกัน ใช้ migration แบบ manual ตามระเบียบใน docs/decisions.md

### Security Rules (บังคับ)

- ห้าม expose `SUPABASE_SERVICE_ROLE_KEY` / `OPENROUTER_API_KEY` ไป client
- Ownership check เสมอใน route handler — อย่าพึ่ง RLS อย่างเดียว (Prisma bypass RLS)
- Validate input ด้วย Zod ทุก endpoint
